# v0.5-03 MD 观察对照报告 — 2HBB WT（×2 副本）与 F31A / K12M / I18V

> **run 类别：观察性对照（observational comparison），非科学结论**
> 日期：2026-11-13｜执行入口：`workbench/gromacs.py`（v0.5-02 正式执行器）
> 模拟时长：每体系 3 ns（共 5 个 run，全部 `succeeded`）
> **3 ns 远不足以收敛；本报告所有数字仅证明"流程可运行、记录可追溯"，所有跨体系差异仅为观察记录，不得解读为突变对稳定性/柔性的影响，不得用于筛选、评分或亲和力判断。**

## 1. 选点（来自 v0.4 S669 评测闭环）

| 体系 | 实验 ΔΔG (kcal/mol, S669) | Rosetta ΔΔG (REU, v0.4) | 选点理由 |
|---|---|---|---|
| WT × 2 副本 | — | — | 建立同协议重复性（噪声）基线 |
| F31A | +2.84 | +5.87 | 去稳定化端（疏水核心 Phe→Ala） |
| K12M | −1.80 | +1.88 | 稳定化端；exp 与 REU **方向分歧**（S669 2HBB 子集已知噪声，v0.4-03 已记录），作为对照观察背景 |
| I18V | +0.07 | +0.17 | 中性端（同类保守替换） |

两列口径不同（kcal/mol vs REU），不可互比；仅作选点背景。

## 2. 起点结构生成（诚实记录）

- 每个突变体复用其 v0.4 run 的 relax 产物与 mutfile，以**相同 seed** 重跑 cartesian_ddg（`dump_pdbs=true`，`executors.run_cartesian_ddg` 新增参数）导出松弛 WT/MUT 结构；
- **ΔΔG 交叉核对 3/3 完全一致**（F31A 5.871 / K12M 1.877 / I18V 0.167）——同 seed 确定性复现的再次实证；
- ⚠️ **起点结构差异（如实）**：三个 run 各自导出的 WT 结构**坐标不同**（输入的 relaxed WT 相同，但 ddG 协议的 RNG 流与该 run 的突变 packing 决策交织，属协议固有现象）。处置：WT 的 MD 参照统一取 f31a run 的 WT 导出；各突变体起点取各自 run 的 MUT 导出；起点差异由 MD 平衡阶段吸收，**不据此下任何结论**；
- 记录：每个结构目录含 `ddg_crosscheck.json`（来源 run、ddg 核对、文件哈希）。

## 4. 观察结果（⚠️ 仅观察）

（自动生成表：`docs/md_2hbb_mutants_v05_table.md`；RMSF 叠加图：`docs/md_2hbb_mutants_rmsf.png`）

| 体系 | RMSD 均值 (nm) | RMSD 后半程 (nm) | T 均值 (K) | RMSF 峰值 (nm) |
|---|---|---|---|---|
| WT rep1 | 0.132 | 0.142 | 299.96 | 0.267 |
| WT rep2 | 0.131 | 0.108 | 299.98 | 0.253 |
| F31A | 0.146 | 0.144 | 299.97 | 0.394 |
| K12M | 0.154 | 0.156 | 299.95 | 0.254 |
| I18V | 0.177 | 0.177 | 299.94 | 0.246 |

**观察记录（不构成结论）**：

1. **副本噪声基线**：WT 双副本 RMSD 均值差 <1%（0.132/0.131），RMSF 峰差 ~5%（0.267/0.253）——同协议、不同种子下的流程重复性观察值。
2. **RMSF 峰值位置**：所有体系的 RMSF 最大值都在 **C 端残基 51**（尾链柔性，与 v0.5-01 冒烟观察一致）。
3. **F31A**：C 端区（res ~42–51）RMSF 抬升至 0.394，超出 WT 副本带（0.253–0.267），中段（~12–16、37）亦偏高。**仅作记录**：起点结构差异与 3 ns 未收敛都可能贡献此观察，不解读为"突变导致柔性增加"。
4. **K12M / I18V**：RMSF 峰值落在 WT 副本带内（0.254/0.246）；I18V 的 RMSD 均值（0.177）高于其他体系，但其起点结构与其他体系不同，同样不解读。
5. 恒温器全部按 300 K 工作（299.94–299.98 K），压强/势能量级正常——流程健康度一致。
