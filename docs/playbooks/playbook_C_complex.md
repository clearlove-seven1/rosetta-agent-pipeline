# Playbook C — 多链 / 蛋白-蛋白复合物

> 引用方式:`suggest_plan` 工具输出本文件指引;`search_rosetta_docs` 检索时计划手册优先命中。
> 铁律同前:计划是建议;科学参数由工具默认值锁定;缺条件必须停下问,不猜测。

## 适用条件

- ≥2 条标准蛋白链(蛋白-蛋白复合物、多结构域多链体系)。
- 目标:界面残基突变扫描、界面能量分析。**分子对接不在本系统**——对接复合物请人工接力后拿回来分析。

## 前置条件(缺 → 停下问)

- [ ] 链 ID 明确;**位点必须带链号(`A_76`/`B_76`)**——只写数字在多链同号时会报错并列出候选链,
      这是防错特性,不是故障;
- [ ] 缺主链原子(N/CA/C)的残基会在弛豫清洗时被剔除并计入 anomalies(与 Rosetta 实际行为一致,
      2026-11-21 地面真值验证);预检阶段会如实报告;
- [ ] 带配体的复合物 = 本手册 + Playbook B 的配体章节。

## 步骤与默认参数

| 步骤 | 工具 | 默认参数 | 说明 |
|---|---|---|---|
| 1 体系判定 | `suggest_plan` | — | 输出链清单、各链残基数、HETATM |
| 2 弛豫 | `run_cartesian_relax` | nstruct=2 | 多链整体弛豫(链间相对取向 = 输入构象,不会重对接) |
| 3 界面分析 | `analyze_interface` | 打包态/分离态能量 | dG_separated/dG_cross 等;**文档列名 ≠ 旗标名,勿照抄**(11-14 实测教训) |
| 4 突变扫描 | `run_saturation_mutagenesis` | iterations=3 | 位点带链号;建议先扫界面 hotspot,全链饱和算力×链数 |
| 5 解读 | `ddg_results.txt` | ΔΔG(REU) | 复合物背景下的单点稳定性变化 |

## 停止条件(必须停下问用户)

- 链歧义/链名不存在 → 报错列候选链,等用户确认;
- 界面工具失败 → 读日志定位(常见:缺主链残基被剔除导致链断裂);
- 全链饱和扫描的算力预算 → 列出"位点数×19×耗时"估算,等用户确认范围;
- 多链体系弛豫**不会重新对接**——输入构象决定链间取向,需要改取向请人工接力对接工具。

## 产物与边界

- 同 Playbook A/B;`manifest.chains` 记录链清单,`target_sites` 带链号;
- 复合物 ΔΔG 解释需结合界面分析:稳定性变化 ≠ 结合亲和力变化,两者口径不同,报告分开陈述。
