# 06 · 实验对照与可信度评估

本章详细介绍 Rosetta Agent 自动评估 ΔΔG 预测可信度的机制。

## 1. 为什么需要实验对照

Rosetta 算出来的 ΔΔG 是**物理能量函数**估算的预测值，但：
- 物理模型有偏差
- 训练数据和真实分布不一致
- 不同蛋白体系精度差异大

如果不和实验对照，用户**无法知道预测值有多可信**。本项目自动接两个权威实验数据库做交叉验证。

## 2. skempi_eval 节点

### 2.1 节点定位

```python
def skempi_eval_node(state, config=None, **kwargs):

    # 5. 合并报告

```

## 3. SKEMPI 2.0 评估

### 3.1 SKEMPI 数据库介绍

**SKEMPI 2.0**（[来源](https://life.bsc.es/pid/skempi2)）收录了 ~7000 条蛋白-蛋白相互作用（PPI）界面的突变实验数据，每条记录包含：

- PDB ID
- 突变位点（链 + 残基号 + 原氨基酸 + 突变氨基酸）
- 实验测得的 ΔΔG_bind（结合自由能变化，kcal/mol）
- 实验方法（ITC、SPR 等）

### 3.2 evaluate_against_skempi 实现

```python
@tool
def evaluate_against_skempi(pdb_id: str, ddg_results_path: str = "") -> str:
    """蛋白-蛋白 ΔΔG 预测 vs 实验 ΔΔG Pearson 相关性"""
    # 1. 加载 SKEMPI 2.0 CSV
    skempi = _load_skempi()  # 缓存

    # 2. 解析 ddg_results.txt
    predicted = _build_predicted_dict(ddg_path)  # {key: predicted_ddg}

    # 3. 按相同位点匹配
    matched = []
    for skempi_entry in skempi:
        if skempi_entry["pdb_id"] != pdb_id:
            continue
        key = _skempi_key_from_parsed(skempi_entry)
        if key in predicted:
            matched.append((predicted[key], skempi_entry["exp_ddg"]))

    # 4. 算 Pearson + p-value
    r, p = _pearson([m[0] for m in matched], [m[1] for m in matched])

    # 5. 三档评估
    if r > 0.7: tier = "强"
    elif r > 0.4: tier = "中"
    else: tier = "弱"

    return f"SKEMPI 评估：Pearson r={r:.3f}, p={p:.4g}, 匹配 {len(matched)} 个位点, {tier}相关"
```

### 3.3 Key 匹配逻辑（核心难点）

**预测 ΔΔG 的 key 格式**（来自 `ddg_results.txt`）：
```
Q_A71_L    -0.9360
I_A72_M    -0.0050
```

格式：`{原AA}_{链}_{PDB编号}_{新AA}`（如 `Q_A71_L` 表示 A 链 71 位 Gln 突变为 Leu）

**SKEMPI 的 key 格式**：
```
PDB: 1BRS, Mutation: DA41A
```
格式：`{链}{原AA}{PDB编号}{新AA}`

**归一化函数**：

```python
def _parse_ddg_key(key: str) -> dict:
    """把 'Q_A71_L' 解析成 {wt: 'Q', chain: 'A', resnum: '71', mut: 'L'}"""
    parts = key.split("_")
    return {"wt": parts[0], "chain": parts[1], "resnum": parts[2], "mut": parts[3]}

def _parse_skempi_mutation(mut_str: str) -> dict:
    """把 'DA41A' 解析成 {chain: 'D', wt: 'A', resnum: '41', mut: 'A'}"""
    chain = mut_str[0]
    wt = mut_str[1]
    resnum = mut_str[2:-1]
    mut = mut_str[-1]
    return {"chain": chain, "wt": wt, "resnum": resnum, "mut": mut}
```

**关键**：**链不参与匹配**（不同数据库的链标识可能不一致，按 (wt, resnum, mut) 三元组匹配）。

### 3.4 Pearson 相关系数

```python
def _pearson(x, y):
    """皮尔逊积差相关系数"""
    n = len(x)
    mean_x = sum(x) / n
    mean_y = sum(y) / n
    cov = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(x, y)) / n
    std_x = (sum((xi - mean_x) ** 2 for xi in x) / n) ** 0.5
    std_y = (sum((yi - mean_y) ** 2 for yi in y) / n) ** 0.5
    r = cov / (std_x * std_y) if std_x * std_y > 0 else 0
    # t 检验 + p-value
    t = r * (n - 2) ** 0.5 / (1 - r ** 2) ** 0.5 if abs(r) < 1 else float('inf')
    p = 2 * (1 - _student_t_cdf(abs(t), n - 2))
    return r, p
```

**评估标准**：

| Pearson r | 档位 | 含义 |
|---|---|---|
| > 0.7 | 强 | 预测与实验高度一致 |
| 0.4 - 0.7 | 中 | 趋势对，绝对值有偏差 |
| < 0.4 | 弱 | 不可信，建议人工复核 |

### 3.5 常见失败模式

| 现象 | 原因 |
|---|---|
| 报"未找到 PDB XXX 的记录" | PDB 不在 SKEMPI 收录范围（SKEMPI 只收蛋白-蛋白相互作用，不收单链酶） |
| 报"位点重叠 0" | `ddg_results.txt` 的 key 格式与 SKEMPI 解析对不上（链参与匹配导致） |

## 4. PDBbind v2020 评估

### 4.1 PDBbind 数据库介绍

**PDBbind v2020**（[来源](http://www.pdbbind.org.cn/)）收录了 ~19000 条蛋白-小分子复合物的实验结合亲和力数据（Kd/Ki/IC50）；本项目 `pdbbind_v2020.csv` 采用 [Leak-Proof PDBBind](https://github.com/THGLab/LP-PDBBind) 重新整理的版本（19443 条），按集合分：

- **general set**：高质量精选集
- **refined set**：进一步筛选
- **core set**：基准测试集

### 4.2 evaluate_against_pdbbind 实现

```python
@tool
def evaluate_against_pdbbind(pdb_ids: str, score_paths: str = "") -> str:
    """蛋白-小分子 Rosetta score vs 实验 Kd Spearman 秩相关"""
    # 1. 加载 PDBbind v2020 CSV
    pdbbind = _load_pdbbind()

    # 2. 解析多个 PDB（多个 score.sc 文件）
    pdb_id_list = pdb_ids.split(",")

    # 3. 每个 PDB：parse score.sc → 提取 total_score
    scores = []
    kds = []
    for pdb_id, sc_path in zip(pdb_id_list, score_paths.split(",")):
        if pdb_id not in pdbbind:
            continue
        total_score = _parse_score_sc(sc_path)  # 取 total_score 列
        kd = pdbbind[pdb_id]["kd"]
        scores.append(total_score)
        kds.append(kd)

    # 4. 算 Spearman ρ
    rho, p = _spearman(scores, kds)

    # 5. 评估（期望负相关）
    if rho < -0.6: tier = "强"
    elif rho < -0.3: tier = "中"
    else: tier = "弱"

    return f"PDBbind 评估：Spearman ρ={rho:.3f}, p={p:.4g}, 匹配 {len(scores)} 个 PDB, {tier}相关"
```

### 4.3 Spearman 秩相关（vs Pearson）

```python
def _spearman(x, y):
    """斯皮尔曼秩相关系数"""
    n = len(x)
    rank_x = _rank(x)
    rank_y = _rank(y)
    d_squared = sum((rx - ry) ** 2 for rx, ry in zip(rank_x, rank_y))
    rho = 1 - 6 * d_squared / (n * (n ** 2 - 1))
    # ...
    return rho, p
```

**为什么用 Spearman 而非 Pearson**：
- Kd 是非线性尺度（nM → μM 跨数量级）
- Spearman 用秩而非原值，更鲁棒
- **期望负相关**：Rosetta total_score 越低（结构越稳定）≈ Kd 越小（结合越强）

### 4.4 多 PDB 评估的统计学要求

需要**同一蛋白的 ≥3 个不同 PDB ID** 才有 Spearman 统计意义。

例如要评估 HIV protease 的小分子结合预测，需要 3+ 个不同 HIV protease 复合物 PDB（如 1HVR、2BPV、1HXW）。

### 4.5 _parse_score_sc 详解

Rosetta 的 `score.sc` 是 tabular 输出：

```
SEQUENCE: SCORE: total_score description
SCORE:    total_score       fa_atr       fa_rep       fa_sol       fa_intra_rep    ...
SCORE:   -1234.567       -456.789       123.456       234.567       ...
```

提取每行第二列（total_score），多 nstruct 取平均。

## 5. 评估阈值与含义

### 5.1 SKEMPI 阈值（Pearson r，正相关）

| 范围 | 档位 | 含义 |
|---|---|---|
| r > 0.7 | 强 | 预测与实验高度一致，可信 |
| 0.4 < r < 0.7 | 中 | 趋势对，绝对值需校正 |
| r < 0.4 | 弱 | 不可信，建议换参数或人工复核 |

### 5.2 PDBbind 阈值（Spearman ρ，负相关）

| 范围 | 档位 | 含义 |
|---|---|---|
| ρ < -0.6 | 强 | 预测与实验高度一致，可信 |
| -0.6 < ρ < -0.3 | 中 | 趋势对，绝对值需校正 |
| ρ > -0.3 | 弱 | 不可信 |

### 5.3 不在数据库怎么办

**优雅降级**：节点返回 `未找到 PDB XXX 的记录`，**不影响后续 summarize**。

## 7. 局限性诚实声明

### 7.1 数据库覆盖范围有限

- **SKEMPI**：只收蛋白-蛋白相互作用，**不包括**单链酶（如 1MC9）
- **PDBbind**：只收蛋白-小分子复合物，HIV protease / thrombin / carbonic anhydrase 等有大量配体
- 其他蛋白类型（蛋白-DNA、蛋白-RNA）不在范围内

### 7.2 PDB ID 命名假设

- 任务目录名必须以真实 4 字符 PDB 代码结尾
- 任务示例：`task_YYYYMMDD_HHMM_<PDB>`
- 真实 PDB ID 由 RCSB 分配（如 `1ABC`、`4HHB`）

### 7.3 Key 匹配的脆弱性

- 链标识不参与匹配（不同数据库链标识可能不同）
- 多突变（multi-mutant）暂未支持
- 残基编号以 PDB 文件为准（insertion code 未处理）

### 7.4 统计学局限性

- Pearson/Spearman 在小样本（< 5）上不可靠
- p-value 没做多重比较校正
- 没考虑系统误差（不同实验方法、不同温度）
