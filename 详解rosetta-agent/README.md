## 项目一句话定义

把 Rosetta 三段式蛋白设计流水线（配体参数化 → Cartesian 弛豫 → 饱和突变 ΔΔG 扫描）从命令行解放为自然语言驱动，通过 LangGraph 多智能体架构 + ESM-2 disorder 过滤 + 实验数据库对照，实现端到端零人工的高通量蛋白工程。
