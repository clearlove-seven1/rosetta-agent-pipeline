### 1.1 章节 1：基础配置与 LLM 初始化（行 1-60）

### 1.3 章节 3：TaskAwareToolNode（行 80-122）

```python
class TaskAwareToolNode(ToolNode):
    def invoke(self, input, config=None, **kwargs):
        if config and "configurable" in config:
            task_id = config["configurable"].get("thread_id", ".")
            target_dir = os.path.join("output", task_id)
            current_workspace.set(target_dir)
        result = super().invoke(input, config=config, **kwargs)
        self._truncate_messages(result)
        return result
```

**职责**：
- 拦截 ToolNode 执行，注入 thread_id → 工作区目录
- 对超长 ToolMessage 做首尾截断（防炸 context window）

**为什么需要**：多用户并发时，每个任务的产物要落到独立目录；LangGraph 的 thread_id 是天然的任务隔离键。

```python
class AgentState(TypedDict):
```

**字段语义**：

### 1.5 章节 5：公共辅助函数（行 152-168）

```python
def _is_tool_error(msg) -> bool:
    if not isinstance(msg, ToolMessage):
        return False
    content = str(msg.content)
    return ("【执行报错】" in content) or ("【系统异常】" in content) or ("【执行失败】" in content)

def _llm_has_tool_call(state: AgentState) -> Literal["tool", "__next__"]:
    last = state["messages"][-1]
    if isinstance(last, AIMessage) and last.tool_calls:
        return "tool"
    return "__next__"
```

**约定**：
- 工具报错必须以 `【执行报错】` / `【系统异常】` / `【执行失败】` 开头，路由层才能识别
- LLM 节点出口必须产生 tool_call，否则视为异常

### 1.6 章节 6：节点工厂（行 170-294）

```python
def _make_step_llm_node(step_num: int, system_prompt: str, bound_tools):
    step_llm = llm.bind_tools(bound_tools)
    def _node(state: AgentState):
        response = step_llm.invoke([SystemMessage(content=system_prompt)] + list(state["messages"]))
        return {"messages": [response], "pipeline_step": step_num}
    _node.__name__ = f"step{step_num}_llm_node"
    return _node

def _make_step_tool_node(step_num: int, bound_tools):
    inner = TaskAwareToolNode(bound_tools)
    def _node(state: AgentState, config=None, **kwargs):
        result = inner.invoke(state, config=config, **kwargs)
        new_msgs = result.get("messages", [])
        update = {"messages": new_msgs}
        last = new_msgs[-1] if new_msgs else None
        if last and _is_tool_error(last):
            update["failed_step"] = step_num
            update["retry_count"] = state.get("retry_count", 0) + 1
        return update
    _node.__name__ = f"step{step_num}_tool_node"
    return _node
```

**工厂模式的好处**：3 个 step 节点用同一份代码生成，只是 step_num / system_prompt / bound_tools 不同。

**关键状态写入**：
- `pipeline_step`：进入该步骤时记录，便于 UI 观察
- `failed_step` + `retry_count`：失败时写入，供 repair 回路路由

```python
INTENT_SYSTEM = (
    "你是任务意图路由器。根据用户最新输入，只回复以下三种之一：\n"
    "  pipeline —— 用户提供了蛋白+配体并明确要求执行 Rosetta 流水线\n"
    "  query    —— 用户在询问 Rosetta 文档、参数、报错含义\n"
    "  chat     —— 问候、寒暄或与本系统无关的话题"
)

def router_node(state: AgentState) -> AgentState:
    if state.get("intent"):
        return {}  # 已分类过，跳过

    # 启发式快速判定
    pipeline_markers = ["突变位点", "目标突变位点", "【系统强制规则】", "【系统强制批量流水线】"]
    if any(m in str(last_user) for m in pipeline_markers):
        return {"intent": "pipeline"}

    # 其余走 LLM 分类
    resp = llm.invoke([SystemMessage(content=INTENT_SYSTEM), HumanMessage(content=str(last_user))])
    intent = (resp.content or "").strip().lower()

    if intent not in ("pipeline", "query", "chat"):
        intent = "chat"
    return {"intent": intent}
```

### 2.2 章节 1.5：编号体系核心（行 73-166）

```python
_AA_3TO1 = {
    "ALA": "A", "CYS": "C", "ASP": "D", ...
}

def _build_rosetta_numbering(pdb_path: str):
    """扫描 PDB 中所有 CA 原子，构建双向编号映射"""
    rosetta_to_pdb = {}
    pdb_to_rosetta = {}
    wt_aa_dict = {}
    rosetta_idx = 1
    with open(pdb_path, 'r') as f:
        for line in f:
            if line.startswith("ATOM") and line[12:16].strip() == "CA":
                chain = line[21].strip()
                # ... 解析链、残基号、氨基酸
                rosetta_to_pdb[rosetta_idx] = f"{chain}_{resnum}"
                pdb_to_rosetta[f"{chain}_{resnum}"] = rosetta_idx
                wt_aa_dict[rosetta_idx] = _AA_3TO1[resname]
                rosetta_idx += 1
    return rosetta_to_pdb, pdb_to_rosetta, wt_aa_dict
```

**为什么需要这个**：Rosetta 用**绝对行号**（从 1 开始数所有 CA 原子），而 PDB 文件用 **chain + 残基号**（如 `A:76`）。这两套编号必须双向映射。

**模块唯一性**：整个流水线的 PDB↔Rosetta 映射**只在 `_build_rosetta_numbering` 这里实现**，调用方禁止二次映射——这是项目里的"编号铁律"。
