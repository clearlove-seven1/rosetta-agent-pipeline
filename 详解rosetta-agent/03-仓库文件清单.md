## 2. 核心文件逐个详解

### 2.1 `rosetta_agent.py`（1025 行 · 主程序）

**职责**：项目入口，组装 LangGraph 图、启动 Gradio Web / CLI。

**核心结构**（按章节）：

| 章节 | 行号 | 内容 |
|---|---|---|
| 1. 基础配置 | 1-60 | 加载 .env、初始化 ChatOpenAI |
| 2. 工具分组 | 62-76 | GENERAL_TOOLS / REPAIR_TOOLS / STEP1-3_TOOLS |
| 3. 任务感知工具节点 | 80-122 | `TaskAwareToolNode` 继承 `ToolNode` |
| 4. 主图状态定义 | 124-150 | `AgentState` TypedDict |
| 5. 公共辅助 | 152-168 | `_is_tool_error` / `_llm_has_tool_call` |
| 6. 节点工厂 | 170-294 | `_make_step_llm_node` / `_make_step_tool_node` / `progress_poll_node` |
| 7. 流水线子图 | 297-486 | `build_pipeline_subgraph()` 核心 |
| 8. 主图节点 | 489-580 | router / reply / summarize |
| 9.5 skempi_eval 节点 | 583-633 | 实验对照评估 |
| 10. 构建主图 | 636-668 | `workflow = StateGraph(...)` |
| 11. 后台打包 | 671-702 | `package_results()` |
| 12. UI 主题 | 705-720 | custom_theme |
| 13. 任务提交 | 723-947 | `submit_task()` / `run_cli()` |
| 14. Gradio 页面 | 950-1003 | `with gr.Blocks() as demo` |
| `__main__` | 1006-1027 | argparse + 启动 web/cli |

**关键技术**：
- `bind_tools()` 给每个 step 的 LLM 物理限制工具
- `add_conditional_edges` 路由成功/失败
- `MemorySaver` 提供 session 内状态持久化
- `TaskAwareToolNode` 拦截注入 thread_id 工作区

### 2.2 `rosetta_tools.py`（1320+ 行 · 工具库）

**职责**：所有 @tool 装饰函数的实现 + 内部辅助函数。

**章节分布**：

| 章节 | 行号 | 内容 |
|---|---|---|
| 0. 环境配置 | 15-33 | ROSETTA_BIN / contextvars 工作区 |
| 1. 基础读取诊断 | 35-70 | `read_file` / `check_logs` |
| 1.5 编号体系 | 73-166 | `_build_rosetta_numbering` PDB↔Rosetta 映射 |
| 2. 三段流水线工具 | 168-512 | `parameterize_ligand` / `run_cartesian_relax` / `run_saturation_mutagenesis` |
| 3. 修复工具 | 515-569 | `diagnose_and_fix` / `auto_repair` |
| 4. SKEMPI 评估 | 571-820 | `evaluate_against_skempi` Pearson |
| 5. ESM-2 disorder | 822-1108 | `predict_disorder` / `predict_disorder_struct` |
| 6. PDBbind 评估 | 1110-1294 | `evaluate_against_pdbbind` Spearman |
| 7. RAG 检索 | 1296+ | `search_rosetta_docs` + Chroma |

**12 个 @tool 函数清单**：
1. `read_file` - 读任意文件
2. `check_logs` - tail 日志
3. `get_rosetta_numbering` - PDB↔Rosetta 映射核对
4. `parameterize_ligand` - 配体参数化
5. `run_cartesian_relax` - 弛豫
6. `run_saturation_mutagenesis` - 突变扫描
7. `diagnose_and_fix` - 报错诊断
8. `auto_repair` - 自动修复
9. `evaluate_against_skempi` - SKEMPI 对照
10. `predict_disorder` - disorder 预测（人读报告）
11. `evaluate_against_pdbbind` - PDBbind 对照
12. `search_rosetta_docs` - RAG 检索

另有非 @tool 的辅助函数 `predict_disorder_struct`（disorder 机器读 + 落盘 CSV），
供 LangGraph `disorder_check` 节点内部调用，不对 LLM 暴露。

### 2.3 `run_cli.sh`（17 行 · 批量 CLI）

```bash
for pdb in inputs/pdbs/*.pdb; do
    python rosetta_agent.py \
        --mode cli \
        --protein "$pdb" \
        --mutation 71,72 \
        --params "并发数 48, 延迟 1.5" \
        --msg "..."
done
```

简单 `for` 循环遍历 `inputs/pdbs/` 下所有 PDB，依次调用 `rosetta_agent.py --mode cli`。

### 2.15 `rosetta_mcp_server.py`（MCP Server）

把 rosetta_tools.py 的 12 个原子工具通过 MCP 协议暴露给 Claude Desktop / Cursor / Trae，
客户端 LLM 可直接编排三段流水线（与 LangGraph 共用同一套工具实现，零逻辑重复）。

- **工作区注入**：LangGraph 用 `TaskAwareToolNode` 注入 thread_id 工作区；MCP Server 用
  `_apply_workspace()` 在每次工具调用前注入（进程级全局 `_ACTIVE_TASK` 存当前任务，
  规避 contextvar 在 MCP 独立 async context 间不持久的问题）
- **Schema 自动生成**：`functools.wraps` 保留原函数签名与 docstring，MCP inputSchema
  由官方 SDK（`mcp.server.fastmcp`）自动提取，无需手工维护两套工具定义
- **3 个管理工具**：`create_task`（建任务工作区 + PyMOL 自动分离配体）、`list_tasks`
  （列任务与产物状态）、`set_workspace`（切工作区）
- **传输**：stdio（默认，Claude Desktop / Cursor）或 `--transport sse`（远程）

## 3. 文件间依赖关系

```
rosetta_agent.py
   ├── 导入 rosetta_tools.py 的所有 @tool 函数
   ├── 构建 LangGraph 主图（StateGraph）
   ├── 构建流水子图（StateGraph）
   └── 启动 Gradio Web / argparse CLI
              │
              ▼
rosetta_tools.py
   ├── @tool 装饰器（LangChain 注册）
   ├── 调 Rosetta 二进制（subprocess）
   ├── 调 PyMOL 二进制（subprocess）
   ├── 调 ESM-2（Python API）
   └── 读 .csv / .txt 数据文件
              │
              ▼
Rosetta / PyMOL / ESM-2（外部依赖）
```

## 4. 数据流向图

```
用户输入（Web/CLI）
   │
   ▼
rosetta_agent.py（LangGraph 主图）
   │
   ├─→ router 节点（意图分类）
   │
   ├─→ pipeline 子图
   │     │
   │     ├─→ step1：parameterize_ligand（生成 .params）
   │     ├─→ step2：run_cartesian_relax（生成 wt_relaxed.pdb）
   │     ├─→ disorder_check（ESM-2 disorder 分数）
   │     └─→ step3：run_saturation_mutagenesis（生成 .ddg）
   │
   ├─→ skempi_eval 节点
   │     ├─→ evaluate_against_skempi（蛋白-蛋白 ΔΔG Pearson）
   │     └─→ evaluate_against_pdbbind（蛋白-小分子 Kd Spearman）
   │
   └─→ summarize 节点（输出最终答复）
              │
              ▼
Gradio Chatbot / CLI stdout
```
