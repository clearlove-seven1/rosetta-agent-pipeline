# 09 · ESM-2 模型原理与本项目中的应用

本章是 ESM-2 的专题深度讲解，重点回答三个问题：

1. **ESM-2 是什么**：从蛋白语言模型的起源到 ESM-2 的定位
2. **它怎么工作**：Transformer + 掩码语言建模的原理
3. **本项目怎么用**：disorder 预测的具体实现与策略选择

## 1. 蛋白语言模型的诞生背景

### 1.1 为什么蛋白需要"语言模型"

2017 年 Transformer 诞生后，NLP 领域出现了一个惊人发现：**用海量文本无监督预训练的语言模型，能学到语法、语义、甚至世界知识**（如 GPT、BERT）。

生物学家立刻想到：**氨基酸序列是不是也能这样学？**

直觉基础：

| NLP | 蛋白 |
|---|---|
| 单词 | 氨基酸残基（A/C/D/E/F/G/H/I/...） |
| 句子 | 蛋白序列（一维链） |
| 语法 | 蛋白折叠的物理约束 |
| 语义 | 蛋白结构与功能 |
| 语料库 | UniRef、UniProt、PDB |

如果一个模型能从亿级蛋白序列中学到"蛋白语法"，它就相当于**学会了进化论留下的物理化学规律**——而这正是蛋白设计的核心知识。

### 1.2 ESM 系列演进

Meta FAIR（Facebook AI Research）团队推出的 ESM 系列：

| 版本 | 年份 | 关键贡献 |
|---|---|---|
| ESM-1 | 2019 | 首次证明 Transformer 能从序列学结构信息 |
| ESM-1b | 2020 | 更大模型（650M）+ 更多数据，性能显著提升 |
| **ESM-2** | **2020** | **规模化的系统研究 + 开源 8M~15B 全家桶** |
| ESMFold | 2022 | 用 ESM-2 嵌入直接预测三维结构（端到端蛋白结构预测） |
| ESM-3 | 2024 | 多模态（序列 + 结构 + 功能标记），可生成全新蛋白 |

本项目用的是 **ESM-2（2020）**，原因：
- 开源成熟、社区活跃
- 模型规模多档可选（35M 够用、648M 精准、15B 极致）
- 提供 pre-trained weights 直接下载
- 配套 `fair-esm` 库使用简单

## 2. ESM-2 架构详解

### 2.1 整体架构

ESM-2 是 **Transformer Encoder-only** 架构（与 BERT、RoBERTa 同源）：

```
输入序列：M K T A Y I A L ...
              ↓
        氨基酸嵌入（Embedding）
              ↓
    [Transformer Block] × N
      ├─ Multi-Head Self-Attention
      ├─ Feed-Forward Network
      └─ Layer Normalization + Residual
              ↓
     每个残基的上下文表示
   (h_1, h_2, ..., h_L)
              ↓
       任务特定输出头
   （本项目：disorder 概率）
```

### 2.2 关键设计选择

**（1）Encoder-only（不是 Decoder）**

不像 GPT（Decoder-only）做生成，ESM-2 用 BERT 风格的双向注意力——每个残基能看到**左右所有上下文**。因为蛋白序列不像文本有"下一句"概念，整条链就是完整语义。

**（2）RoBERTa 风格训练**

- 静态掩码（在数据预处理时一次性掩码）
- 取消 NSP（下一句预测）任务——蛋白没有"句子对"概念
- 更大的 batch、更长的训练

**（3）Tokenizer**

每个氨基酸一个 token（不是字符级），词表大小 = 20（标准氨基酸）+ 特殊 token（BOS、EOS、PAD、UNK、+ 非标准氨基酸如 MSE）。

**（4）位置编码**

可学习的位置嵌入（learned positional embedding），最大长度 1024。

### 2.3 ESM-2 模型规模档位

ESM-2 提供从 8M 到 15B 参数的多档模型：

| 模型 | 层数 | 隐藏维度 | 参数量 | 用途 |
|---|---|---|---|---|
| esm2_t6_8M_UR50D | 6 | 320 | 8M | 极轻量 |
| **esm2_t12_35M_UR50D** | **12** | **480** | **35M** | **本项目用** |
| esm2_t30_150M_UR50D | 30 | 640 | 150M | 中等 |
| esm2_t33_650M_UR50D | 33 | 1280 | 650M | 高精度 |
| esm2_t36_3B_UR50D | 36 | 2560 | 3B | 接近极限 |
| esm2_t48_15B_UR50D | 48 | 5120 | 15B | 旗舰 |

**本项目选 t12 35M 的理由**：

- 体积小（~60MB），下载快、不占磁盘
- 推理快（CPU 上 100 残基 1-2 秒）
- disorder 预测任务上精度够用（小模型已经能学到关键的进化保守性信号）
- 可选升级到 t33 650M（GPU 推荐）

**"UR50D" 后缀含义**：
- U = UniRef
- R = 序列聚类（去冗余）
- 50 = UniRef50 聚类阈值（50% 相似度）
- D = 包含所有 UniRef50 序列（不加 D 只用训练集）

## 3. ESM-2 训练方法：掩码语言建模（MLM）

### 3.1 训练任务

ESM-2 用 BERT 经典的**掩码语言建模**：

```
原始序列：M K T A Y I A L
掩码后：  M K [MASK] A Y I A L
目标预测：在 [MASK] 位置应该是哪个氨基酸？
```

具体步骤：

1. 输入蛋白序列（最长 1024 残基）
2. 随机选 **15%** 的位置做变换：
   - **80%** 替换为 `[MASK]`
   - **10%** 替换为随机氨基酸
   - **10%** 保持不变
3. 模型预测这些位置的原始氨基酸
4. 损失函数 = 交叉熵（只对被选中的 15% 位置计算）

### 3.2 为什么 80/10/10 比例

这个比例来自 BERT 的实验：
- 80% `[MASK]`：让模型学会"补全"
- 10% 随机：让模型不只依赖 `[MASK]` token（避免预训练-微调 mismatch）
- 10% 保持：让模型学会"上下文一致性"——同样的上下文应该给同样的输出

### 3.3 训练数据规模

ESM-2 在 **UniRef50（2020-03）** 上训练：

- 总序列数：**~60M** 条
- 总残基数：**~ billions**
- 训练轮次：跨多个 epoch
- 总算力：数千 GPU-days

**关键点：完全无监督，不需要任何标签**——进化本身（亿万年的自然选择）就是"标签"。一个在进化中被保留的蛋白，必然是**结构稳定 + 功能合理**的。

## 4. ESM-2 学到了什么

### 4.1 涌现的结构信息

最令人惊讶的发现：**只用一维序列训练的 ESM-2，注意力图能直接预测三维接触图**。

具体机制：

- 蛋白序列中两个空间上接近的残基（如 β-折叠的两条链），在进化中往往**协同突变**（compensatory mutations）
- ESM-2 看到大量这种协同模式后，**隐式学会**了"这两个位置经常一起变"
- 注意力权重高的残基对 ≈ 空间接触的残基对

### 4.2 氨基酸嵌入的语义

t-SNE / UMAP 可视化 ESM-2 嵌入：

```
        疏水
       (V/I/L/M/F/W)
            |
    带正电 ─┼─ 带负电
   (K/R/H)   |    (D/E)
            |
        极性
      (S/T/N/Q/Y)
            |
       特殊 (C/P/G)
```

**相似化学性质的氨基酸，嵌入空间相邻**——这是模型自己学的，不是人工标注。

### 4.3 进化保守性信息

嵌入向量的"特异性"反映进化保守性：
- 高度保守位点（如活性位点）→ 嵌入独特
- 易变位点（表面 loop）→ 嵌入接近平均

**对本项目的关键启示**：**保守性低的区域 ≈ 无序区域**——这正是 disorder 预测的理论基础。

## 5. 下游任务：为什么能预测 disorder

### 5.1 Disorder 的生物学意义

蛋白 disorder（无序）指蛋白中**没有稳定三维结构**的区域：

- **结构 disorder**：天然无结构（intrinsically disordered proteins, IDP）
- **构象 disorder**：在不同环境下变构
- **瞬时 disorder**：短时无序（如 loop 翻转）

约 30% 真核生物蛋白含有 ≥30 个残基的 disorder 区。

### 5.2 为什么 ESM-2 能预测 disorder

直觉推理：

1. **进化压力对比**：
   - 结构有序区域 → 强进化压力（一点突变就破坏折叠）→ 序列保守 → ESM-2 嵌入独特
   - 无序区域 → 弱进化压力（怎么变都"差不多"）→ 序列多样 → ESM-2 嵌入接近平均

2. **语言模型困惑度对比**：
   - 结构区域 → 序列高度可预测（mask 后能准确还原）
   - 无序区域 → 序列随机性强（mask 后难以还原）
   - 用**逐位 mask 还原损失**作为 disorder 分数

3. **隐空间几何**：
   - 结构残基的嵌入向量**集中**（clustered）
   - 无序残基的嵌入向量**分散**（spread）
   - 用嵌入方差作为 disorder 指标

### 5.3 主流方法

| 方法 | 原理 | 特点 |
|---|---|---|
| **ESM-2 logits 熵** | mask 位置预测概率分布的熵 | 简单有效 |
| **ESM-2 attention** | 平均注意力权重 | 与结构信息相关 |
| **IUPred3** | 能量函数 + 序列特征 | 专用工具 |
| **SPOT-Disorder** | 深度 CNN + LSTM | 经典深度学习 |
| **flDPnn** | 3-mer 特征 + 神经网络 | 轻量级 |

本项目用**第一种**（ESM-2 logits 熵），因为：
- 复用 ESM-2 模型，不引入新依赖
- 与 ESM-2 训练目标直接对应
- 与结构 disorder 相关性高

## 6. 本项目中的具体实现

### 6.1 代码位置

ESM-2 相关代码在 [rosetta_tools.py 章节 5（行 822-1108）](./04-核心代码详解.md#25-章节-5esm-2-disorder行-822-1108)：

```python
def _predict_disorder_esm2(sequence, residues):
    """ESM-2 推理"""
    from esm import pretrained
    model, alphabet = pretrained.esm2_t12_35M_UR50D()
    batch_converter = alphabet.get_batch_converter()

    # 准备输入
    batch_labels, batch_strs, batch_tokens = batch_converter([("protein", sequence)])

    # 推理
    model.eval()
    with torch.no_grad():
        logits = model(batch_tokens)["logits"][0]  # (L+2, vocab_size)

    # 计算逐位 disorder 概率
    # 用 mask 位置预测分布的负对数似然作为 disorder 分数
    scores = []
    for i, (wt_aa, position_logits) in enumerate(zip(sequence, logits[1:-1])):
        probs = F.softmax(position_logits, dim=-1)
        wt_idx = alphabet.get_idx(wt_aa)
        score = 1.0 - probs[wt_idx].item()  # 越不自信越可能 disorder
        scores.append(score)

    return dict(zip([r[0] for r in residues], scores))
```

### 6.4 双策略自动回退

```python
try:
    from esm import pretrained
    model, alphabet = pretrained.esm2_t12_35M_UR50D()
    USE_ESM2 = True
except (ImportError, OSError):
    USE_ESM2 = False

def _predict_disorder(sequence, residues):
    if USE_ESM2:
        return _predict_disorder_esm2(sequence, residues)
    else:
        return _predict_disorder_heuristic(residues)
```

**回退策略 `_predict_disorder_heuristic`**（无 ESM-2 时用）：

```python
def _predict_disorder_heuristic(residues):
    """B-factor 归一化 + gap 启发式"""
    # 1. 提取每个残基的平均 B-factor
    # 2. B-factor 归一化到 [0, 1]
    # 3. 残基序号 gap 大于阈值的视为 disorder
    scores = {}
    for res in residues:
        b_factor_norm = (res["b_factor"] - min_b) / (max_b - min_b)
        # 高 B-factor 通常对应无序
        gap_penalty = 1.0 if res["has_gap_neighbors"] else 0.0
        scores[res["key"]] = 0.7 * b_factor_norm + 0.3 * gap_penalty
    return scores
```

**为什么不只用启发式**：
- B-factor 受实验条件影响大
- gap 检测不到真实 disorder
- ESM-2 准确度高得多（论文 ~0.85 AUC vs 启发式 ~0.65）

## 7. ESM-2 的替代方案对比

### 7.1 专用 disorder 预测器

| 工具 | 原理 | 精度 | 速度 |
|---|---|---|---|
| **IUPred3** | 能量函数 + 序列特征 | 高（~0.85 AUC） | 快 |
| **SPOT-Disorder** | CNN + LSTM + ensemble | 高（~0.89 AUC） | 中 |
| **flDPnn** | 3-mer 特征 + NN | 中（~0.78 AUC） | 极快 |
| **DISOPRED3** | SVM + 序列 profile | 中（~0.80 AUC） | 中 |

### 7.2 为什么本项目选 ESM-2 而非专用工具

**ESM-2 优势**：

- ✅ 不需要额外安装（已经有 `fair-esm`）
- ✅ 一次推理可获取多种下游任务结果（disorder + 嵌入 + 接触图）
- ✅ 与 Transformer 现代架构对齐
- ✅ 论文质量保证

**ESM-2 劣势**：

- ❌ 不是专门为 disorder 训练
- ❌ 精度比 SPOT-Disorder 略低（~0.83 vs ~0.89）
- ❌ 模型体积大（35M vs IUPred3 几百 KB）

**本项目权衡**：复用 + 通用性 > 极致精度。**未来可加入 SPOT-Disorder 作为 ensemble**。

### 7.3 与其他蛋白语言模型对比

| 模型 | 出品方 | 规模 | 特色 |
|---|---|---|---|
| **ESM-2** | Meta FAIR | 8M~15B | 最流行，开源 |
| ProtBERT | 德国 Rostlab | 420M | BERT 风格 |
| ProtT5 | 谷歌 / Rostlab | 3B~11B | T5 风格 encoder-decoder |
| AlphaFold | DeepMind | - | 结构预测，非语言模型 |
| ProGen2 | Salesforce | 151M~6.4B | 生成式，可设计新蛋白 |

## 8. ESM-2 在本项目的局限

### 8.1 模型能力边界

1. **序列长度限制**：max 1024 残基，超长蛋白需分段
2. **非标准氨基酸**：MSE、SEP 等可能识别错
3. **多链处理**：本项目简化成单链拼接（链信息保留但连接符特殊处理）
4. **零样本 vs 微调**：本项目用 zero-shot（不微调），精度有上限

### 8.2 disorder 阈值的局限

`DISORDER_THRESHOLD = 0.5` 是经验值，不同蛋白最优阈值不同：

- 高度 disorder 蛋白：阈值 ~0.3
- 高度结构蛋白：阈值 ~0.6

**改进方向**：让阈值根据预测分数分布自适应（Otsu's method）。

### 8.3 与 Rosetta ΔΔG 的耦合假设

本项目假设 "disorder 位点跑 Rosetta ΔΔG 不可信"，但这是**经验假设**，缺乏系统验证。

**未来工作**：
1. 收集 disorder 区域的 ΔΔG 预测 vs 实验数据
2. 量化 disorder 与 ΔΔG 精度的关系
3. 训练一个"基于 disorder 分数的 ΔΔG 校正模型"
