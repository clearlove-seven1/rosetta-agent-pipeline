# 05 · 对接、相互作用与配体

分子对接（Molecular Docking）是 Rosetta 在**药物发现**领域的核心应用。本章涵盖蛋白-蛋白、蛋白-配体、蛋白-肽等对接工具。

## 1. 分子对接总览

### 1.1 对接分类

| 类型 | 受体 | 配体 | 典型应用 |
|---|---|---|---|
| **蛋白-蛋白对接** | 蛋白 | 蛋白 | 信号通路、抗体 |
| **蛋白-配体对接** | 蛋白 | 小分子 | 药物发现 |
| **蛋白-肽对接** | 蛋白 | 短肽 | 抑制剂设计 |
| **蛋白-核酸对接** | 蛋白 | DNA/RNA | 转录调控 |
| **蛋白-糖对接** | 蛋白 | 糖类 | 糖生物学 |
| **共价对接** | 蛋白 | 共价抑制剂 | 共价药物 |

### 1.2 对接的两大步骤

```
1. 全局采样
   - 在受体表面平移/旋转配体
   - 生成上千个初始构象

2. 局部精修
   - 对每个候选构象做能量最小化
   - 按能量排序，top hits 是预测结合模式
```

### 1.3 与其他对接软件对比

| 软件 | 特点 |
|---|---|
| **AutoDock / Vina** | 经典，免费，小分子为主 |
| **GOLD** | 商业，金标准 |
| **Glide** | Schrödinger 商业 |
| **FlexX** | 商业 |
| **ZDOCK** | 蛋白-蛋白对接专用 |
| **HADDOCK** | 数据驱动对接 |
| **RosettaDock** | 蛋白-蛋白金标准 |
| **RosettaLigand** | 蛋白-配体 |
| **DiffDock** | ML 时代对接 |

**Rosetta 的定位**：物理评分最准、采样最全面、协议最丰富。

## 2. 蛋白-蛋白对接（RosettaDock）

### 2.1 概述

**RosettaDock** 是蛋白-蛋白对接领域**事实标准**：

- 1998 年首次发布（Gray et al.）
- 多版迭代，最新版支持柔性对接

### 2.2 核心算法

**两阶段对接**：

```
阶段 1：刚性对接（Rigid-body Docking）
   - 蒙特卡洛采样受体-配体相对位置
   - 每个移动：受体固定，配体绕质心随机旋转 + 平移
   - 关键平动：平移 1-3 Å，旋转 5-15°
   - 评分：ref2015 能量函数
   - 输出：~1000-10000 个构象

阶段 2：柔性对接（Flexible Docking）
   - 取阶段 1 top hits
   - 加上局部侧链 packing + backbone 微调
   - 重新评分
   - 输出：~100-1000 个最终构象
```

### 2.3 命令

```bash
docking_protocol.linuxgccrelease \
    -s receptor_ligand.pdb \
    -partners A_B \
    -dock_pert 3 8 \
    -nstruct 1000 \
    -out:file:silent docking.silent
```

**关键参数**：

| 参数 | 含义 |
|---|---|
| `-partners A_B` | A 链 = 受体，B 链 = 配体 |
| `-dock_pert 3 8` | 平移扰动 3 Å，旋转扰动 8° |
| `-nstruct 1000` | 生成 1000 个结构 |
| `-spin` | 允许相对旋转 |
| `-translate` | 允许相对平移 |

### 2.4 评估对接结果

**InterfaceAnalyzer** 评估对接质量：

```bash
InterfaceAnalyzer.linuxgccrelease \
    -s docked.pdb \
    -interface A_B \
    -compute_packstat \
    -pack_together
```

输出指标：
- `dG_separated` / `dG_complex` → 界面能
- `interface_delta_SASA` → 接触面积
- `sc_value` → shape complementarity（形状互补）
- `packstat` → 包装密度
- `hbonds` / `salt_bridges` → 化学接触

### 2.5 SnugDock（抗体-抗原对接）

**SnugDock** = RosettaDock + CDR 柔性：

```bash
snugdock.linuxgccrelease \
    -s antibody_antigen.pdb \
    -nstruct 1000
```

**特色**：
- CDR-H3 loop 柔性建模
- 抗原侧链 packing
- 抗体框架刚性

**适用场景**：抗体-抗原结合模式预测、亲和力成熟。

### 2.6 CAPRI 比赛表现

**CAPRI**（Critical Assessment of Predicted Interactions）是蛋白-蛋白对接的国际比赛：

- RosettaDock 长期排名前列
- 中等难度 target 准确率 ~70%
- 高难度 target 准确率 ~30%

## 3. 蛋白-配体对接（RosettaLigand）

### 3.1 概述

**蛋白-配体对接**是**药物发现的核心步骤**——给定候选小分子，预测它与蛋白的结合模式。

### 3.2 与 AutoDock Vina 的对比

| 维度 | AutoDock Vina | RosettaLigand |
|---|---|---|
| 速度 | 快（分钟级） | 慢（小时级） |
| 准确度 | 中 | 高 |
| 采样 | 网格搜索 | 蒙特卡洛 |
| 力场 | 经验力场 | 全 Rosetta 力场 |
| 配体柔性 | 有限 | 完全 |
| 共价对接 | 不支持 | 支持 |

### 3.3 工作流

```
1. 准备受体 PDB（clean_pdb.py）
   ↓
2. 准备配体 PDB + mol2
   ↓
3. molfile_to_params.py 生成配体拓扑
   ↓
4. ligand_dock_setup.py 创建对接设置
   ↓
5. ligand_dock_script 跑对接
   ↓
6. extract_pdbs 提取 top hits
   ↓
7. InterfaceAnalyzer 评估
```

### 3.4 ligand_dock_script

```bash
# 1. 生成参数文件
$ROSETTA_TOOLS/molfile_to_params.py \
    -n LIG \
    -p ligand.pdb \
    -o params/

# 2. 准备对接
$ROSETTA_TOOLS/ligand_dock_setup.py \
    receptor.pdb \
    ligand.pdb \
    -C 1 -n LIG \
    --output setup/

# 3. 跑对接
ligand_dock.linuxgccrelease \
    @setup/flags \
    -nstruct 1000
```

### 3.5 RosettaLigand 关键 flags

| Flag | 含义 |
|---|---|
| `-ligand:ligand_ensemble` | 多个配体构象的 ensemble |
| `-ligand:protocol` | 对接协议：low_res / high_res / both |
| `-ex1 -ex2 -ex3` | 增加 rotamer 采样 |
| `-use_input_sc` | 保留输入侧链 |
| `-packing:repack_only` | 只做侧链 packing |

### 3.6 配体参数化

**配体必须在 Rosetta 中注册为 ResidueType**，通过 `.params` 文件：

```
molfile_to_params.py -n LIG -p ligand.pdb -o params/

# 生成：
# LIG.params       # 残基拓扑
# LIG.pdb          # 配体 PDB
# LIG_0001.pdb     # 配体构象
```

**.params 文件结构**：

```
NAME LIG
IO_STRING LIG Z
TYPE LIGAND
AA UNK
ATOM  C1  C   X   -1.00  0.00  1.00  0.00  0.00  -0.00  0.00
ATOM  C2  C   X   -1.00  0.00  1.00  0.00  0.00  -0.00  0.00
...
BOND  C1   C2
...
```

### 3.7 共价对接

**Rosetta 共价对接**用于共价抑制剂（抗癌药、蛋白酶抑制剂）：

```bash
ligand_dock.linuxgccrelease \
    @setup/flags \
    -cstfile covalent_constraints.cst \
    -nstruct 500
```

**covalent_constraints.cst** 定义共价键约束。

## 4. 蛋白-肽对接

### 4.1 FlexPepDock

**FlexPepDock** 是**柔性肽-蛋白对接**的金标准：

- 论文：Raveh et al. 2010 Angew Chem
- 处理长度 5-15 残基的肽

```bash
flexpepdock.linuxgccrelease \
    -s receptor_peptide.pdb \
    -flexpep_prepack \
    -nstruct 1000
```

**算法**：

1. **预 packing**：固定受体，肽侧链 packing
2. **对接**：蒙特卡洛平移/旋转/扭转
3. **优化**：侧链 + backbone 精修

### 4.2 FlexPepDock ab initio

**完全从头对接**：从随机初始位置开始：

```bash
flexpepdock_abinitio.linuxgccrelease \
    -receptor receptor.pdb \
    -peptide peptide_sequence.fasta \
    -nstruct 1000
```

### 4.3 AnchorGrow

**AnchorGrow** 通过锚定残基 + 逐步生长肽：

- 适用：肽段长（> 15 残基）
- 论文：Rosenzweig et al. 2017

### 4.4 Pip

**Pip**（Peptide Inverse-folding Protocol）：从蛋白界面反向设计肽。

### 4.5 应用案例

- **PD-1/PD-L1 抑制剂**：免疫治疗肽
- **BH3 域**：Bcl-2 抑制剂
- **抗菌肽**：新型抗生素

## 5. 界面分析工具

### 5.1 InterfaceAnalyzer

**评估界面质量的核心工具**：

```bash
InterfaceAnalyzer.linuxgccrelease \
    -s complex.pdb \
    -interface A_B \
    -compute_packstat \
    -pack_together \
    -tracer_data_file interface.txt
```

**输出指标**：

| 指标 | 含义 | 理想值 |
|---|---|---|
| `dG_separated` / `dG_complex` | 界面能（kcal/mol） | 越负越好 |
| `dSASA` | 接触面积 | > 1000 Å² |
| `sc_value` | shape complementarity | > 0.7 |
| `packstat` | 包装密度 | > 0.65 |
| `hbonds_int` | 界面氢键数 | > 5 |
| `salt_bridges` | 盐桥数 | > 0 |

### 5.2 PerResidueEnergyBreakdown

**逐残基能量分解**：

```bash
per_residue_energies.linuxgccrelease \
    -s complex.pdb \
    -out:file:silent per_res.silent
```

**用途**：找**热点残基**（hot spot）——对界面能贡献最大的残基。

### 5.3 InterfaceAlaScan（丙氨酸扫描）

**关键残基识别**：

```bash
interface_ddg.linuxgccrelease \
    -s complex.pdb \
    -interface A_B \
    -nstruct 5
```

**ΔΔG > 2 REU 的位点**：关键界面残基（实验上称"hot spot"）。

### 5.4 Symmetry 对称分析

```bash
interface_analyzer.linuxgccrelease \
    -s symmetric_complex.pdb \
    -symmetry:symmetry_definition my_sym.def
```

### 6.4 高通量 ΔΔG 工作流

```
1. 准备突变文件（mut_file）
   格式：1 A 71 19    # 链 A，位置 71，扫描 19 突变体

2. 准备 wild-type 结构（最好 FastRelax 后）

3. 跑 cartesian_ddg（19 个并行任务）

4. 解析 ddg_results.txt

5. 与实验对比（如 SKEMPI 数据库）
```

## 11. 对接准确度评估

### 11.1 CAPRI 评价标准

**CAPRI**（Critical Assessment of PRedicted Interactions）：

| 等级 | RMSD < 1 Å / 接触残基正确率 | 用途 |
|---|---|---|
| 高质量 | RMSD < 1 Å | 发表级别 |
| 中等 | RMSD < 5 Å | 初步验证 |
| 可接受 | 1 个接触残基正确 | 粗筛 |
| 错误 | - | 失败 |

### 11.2 RosettaDock 的典型表现

- 抗体-抗原对接：高精度 50%，中等 30%
- 酶-底物对接：高精度 60%
- 蛋白-肽对接：高精度 40%

### 11.3 影响精度的因素

| 因素 | 影响 |
|---|---|
| 受体构象 | 关键（柔性受体难） |
| 界面亲水性 | 强亲水界面难（脱水能） |
| 构象变化 | 大变构难 |
| 配体柔性 | 高柔性难 |
