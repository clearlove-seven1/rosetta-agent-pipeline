# 04 · 结构预测与建模

蛋白结构预测是 Rosetta **起家的老本行**——1997 年 Baker 实验室从 ab initio 折叠开始。本章涵盖所有结构预测与建模工具。

## 1. 蛋白结构预测总览

### 1.1 三类预测任务

| 任务 | 含义 | 难度 | Rosetta 工具 |
|---|---|---|---|
| **Ab initio / De novo** | 仅给定序列，预测三维结构 | 极难 | AbinitioRelax |
| **同源建模（Homology Modeling）** | 已知同源结构，预测目标结构 | 中 | RosettaCM |
| **Loop Modeling** | 给定整体结构，建模 loop 区 | 中 | KIC / CCD |
| **Domain Assembly** | 多结构域拼接 | 中 | Docking / CM |
| **多构象预测** | 预测蛋白多种构象 | 难 | Backrub / RosettaEnsemble |

### 1.2 结构预测的发展

| 时期 | 主导方法 | 准确度 |
|---|---|---|
| 1970s-1990s | 经验势能 + 模拟退火 | 很差 |
| 2000s | Rosetta ab initio + 片段 | 中（小蛋白 < 100 残基） |
| 2010s | RosettaCM + 模板 | 较好 |
| 2020 | AlphaFold2 | **革命性突破** |
| 2022+ | AlphaFold2/3, ESMFold, RoseTTAFold | 接近实验精度 |

**Rosetta 现状**：结构预测被 AlphaFold 等 ML 工具主导，Rosetta 在**结构精修（relaxation）和 loop 建模**上仍有优势。

## 2. Ab Initio / De Novo 结构预测

### 2.1 核心思想

**1997 年 Rosetta 创立时的主业**：

1. 用 PSI-BLAST 从 PDB 中搜索短片段（3-mer、9-mer）
2. 拼接片段形成完整骨架
3. 用能量函数评估打分
4. 蒙特卡洛采样找最低能量结构

```bash
AbinitioRelax.linuxgccrelease \
    -in:file:fasta input.fasta \
    -in:file:frag3 aa.3mers \
    -in:file:frag9 aa.9mers \
    -nstruct 1000 \
    -out:file:silent abinitio.silent
```

**片段文件** 由 `fragment_picker` 工具生成，需要 PSI-BLAST + PSIPRED（二级结构预测）。

### 2.2 算法细节

**经典 Rosetta ab initio 流程**：

```
阶段 1：粗粒度采样（centroid 模式）
   - 用超简化残基（仅 Cα + Cβ + 代表性侧链）
   - 蒙特卡洛 + 模拟退火
   - 移动：SmallMover、ShearMover、FragmentMover
   - 时间：长（约 70% 总时间）

阶段 2：从粗到细（centroid → fullatom）
   - 切换到全原子模式
   - 加回 20 种标准氨基酸
   - 时间：中

阶段 3：全原子弛豫（fullatom）
   - FastRelax 精修
   - 时间：短（约 5% 总时间）
```

### 2.3 准确度评估

**对 < 100 残基的小蛋白**：

- 早期（2000s）：~50% 能预测到 RMSD < 5 Å
- 现代（2010s）：~70% 能预测到 RMSD < 5 Å

**对 > 150 残基的中等蛋白**：准确度显著下降。

### 2.4 AbinitioRelax vs Abinitio

| 工具 | 特点 |
|---|---|
| `Abinitio` | 纯 ab initio，无最后弛豫 |
| `AbinitioRelax` | 加最后 FastRelax 步骤 |

### 2.5 现代地位

**AlphaFold2/3 已超越 Rosetta 在 ab initio 上的能力**：

- AlphaFold2 准确度：~85% 中等蛋白达到实验级
- Rosetta ab initio：~70% 小蛋白达到中等精度

但 Rosetta 在以下场景仍有价值：

1. **无 MSA（多序列比对）时**：AlphaFold 退化严重，Rosetta 仍可用
2. **快速骨架生成**：用于 de novo 设计的初始骨架
3. **多构象预测**：Rosetta 自然支持 ensemble

## 3. 同源建模（Comparative / Homology Modeling）

### 3.1 经典方法

**当目标蛋白有已知结构的同源序列**（> 30% 序列相似度），可基于模板建模：

```bash
# 1. 找模板
blastpgp -d pdb -i target.fasta -o target.blast

# 2. 准备 alignment
# target.fasta 与 template.pdb 的序列比对

# 3. 跑 RosettaCM
hybridize.linuxgccrelease \
    -in:file:fasta target.fasta \
    -in:file:template_pdb template.pdb \
    -in:file:alignment target_to_template.aln \
    -nstruct 100
```

### 3.2 RosettaCM（Comparative Modeling）

**RosettaCM** 是当前主流同源建模工具：

```bash
rosetta_cm.linuxgccrelease \
    -in:file:fasta target.fasta \
    -in:file:alignment target.template.aln \
    -in:file:template_pdb template.pdb \
    -nstruct 100
```

**优势**：

- 自动识别 alignment 格式
- 自动检测模板-目标序列差异
- 集成 loop 建模

### 3.3 Loop Modeling（最难的部分）

同源建模中**最难的是 loop 区**——alignment 多变、无模板约束。

#### 3.3.1 CCD（Cyclic Coordinate Descent）

**CCD** 通过循环坐标下降闭合 loop：

```bash
loopmodel.linuxgccrelease \
    -in:file:s input.pdb \
    -loops:loop_file loops.txt \
    -loops:remodel quick_ccd
```

#### 3.3.2 KIC（Kinematic Closure）

**KIC** 通过运动学闭环解算：

```bash
loopmodel.linuxgccrelease \
    -in:file:s input.pdb \
    -loops:loop_file loops.txt \
    -loops:refine refine_kic
```

**KIC 是当前 loop 建模的最佳实践**。

#### 3.3.3 Next-gen KIC（NGK）

**Next-Generation KIC**（2019）：

- 用深度学习辅助采样
- Loop 闭合精度提升 30%
- 默认 KIC 协议使用 NGK

### 3.4 partial_thread

**部分序列替换**：将一段序列插入到已有结构中。

```bash
partial_thread.linuxgccrelease \
    -s input.pdb \
    -in:file:fasta new_segment.fasta
```

## 5. Antibody Modeling（抗体建模）

### 5.1 抗体结构组成

```
抗体（Antibody）
├── 重链（Heavy Chain, H）
│   ├── VH: 可变区
│   │   ├── FR1, CDR1, FR2, CDR2, FR3, CDR3, FR4
│   └── CH1, CH2, CH3: 恒定区
└── 轻链（Light Chain, L）
    ├── VL: 可变区
    │   ├── FR1, CDR1, FR2, CDR2, FR3
    └── CL: 恒定区
```

### 5.2 RosettaAntibody

**抗体建模**：给定 VH、VL 序列 + 框架区模板，建模 CDR loop：

```bash
antibody.linuxgccrelease \
    -s antibody_chains.pdb \
    -mode H3 \
    -nstruct 100
```

**重点**：CDR-H3 loop 长度 8-20 残基，建模最难。

### 5.3 SnugDock

**抗体-抗原柔性对接**：

```bash
snugdock.linuxgccrelease \
    -s antibody_antigen.pdb \
    -nstruct 1000
```

### 5.4 抗体应用案例

- **Herceptin**（曲妥珠单抗）：HER2 靶向
- **Humira**（阿达木单抗）：TNF-α 靶向
- **PD-1/PD-L1 抗体**：免疫治疗
- **CAR-T scFv**：CAR-T 细胞治疗

## 6. Homology Modeling（经典）

### 6.1 MODELLER vs Rosetta

| 软件 | 特点 |
|---|---|
| **MODELLER** | 经典同源建模工具（2000s 起），基于约束满足 |
| **RosettaCM** | 基于蒙特卡洛采样 + 能量函数 |

MODELLER 速度快但精度一般；RosettaCM 慢但对 loop 区域更准。

### 6.2 完整工作流

```
1. 目标序列 → PSI-BLAST 搜索 PDB
       ↓
2. 选择多个模板（序列相似度 > 30%）
       ↓
3. 多模板 alignment（clustalw、mafft）
       ↓
4. RosettaCM 同源建模（生成 100-1000 个模型）
       ↓
5. 模型选择（按能量 + RMSD to template）
       ↓
6. loop refine（KIC）
       ↓
7. 全原子弛豫（FastRelax）
       ↓
8. 评估（MolProbity + Rosetta 能量）
```

## 8. Backrub（多构象生成）

### 8.1 核心思想

**Backrub** 通过**小幅度的 backbone 旋转**（5-15°）模拟自然构象变化：

```bash
backrub.linuxgccrelease \
    -s input.pdb \
    -backrub:ntrials 1000 \
    -nstruct 1000
```

**应用**：

- **蛋白质动态学**：模拟 B-factor
- **酶柔性**：理解诱导契合
- **抗体优化**：CDR 柔性探索

### 8.2 RosettaEnsemble

通过 Backrub 生成 ensemble，模拟蛋白自然构象分布。

## 10. Fold-it（游戏化科学）

### 10.1 起源

[fold.it](https://fold.it/) 是华盛顿大学 2008 年发布的**益智游戏**，让非科学家通过玩游戏解决蛋白折叠问题。

### 10.2 玩法

玩家通过：
- 拖拽蛋白结构片段
- 改变氨基酸类型
- 优化能量分数（Rosetta 提供）

得分越高（能量越低），排名越高。

### 10.3 重要成果

**2012 年里程碑**：

- Foldit 玩家设计出**首个由人设计的酶**（Diels-Alder 合成酶）
- 论文：Khatib et al. Nature Biotechnology 2012
- 玩家**没有博士学位**，但游戏技巧 + Rosetta 评分系统让"群体智能"超越传统算法

### 10.4 后续

- Foldit 已扩展到 HIV 蛋白酶、新型结合蛋白等任务
- 是**公民科学**（citizen science）的代表案例

## 13. 结构预测的局限（诚实声明）

### 13.1 仍难以解决的

1. **超大蛋白（> 500 残基）**：即使 AlphaFold 也有 ~30% 失败率
2. **多结构域构象**：多结构域相对取向难预测
3. **膜蛋白**：跨膜区拓扑不准
4. **复杂变构**：构象变化幅度大的预测困难
5. **天然无序蛋白**：IDP 无法预测单一稳定结构

### 13.2 计算资源

| 任务 | 单次时间 | 典型任务数 |
|---|---|---|
| Ab initio (100 残基) | ~24 小时 | 100-1000 |
| RosettaCM (300 残基) | ~6 小时 | 100 |
| Loop Modeling (10 残基) | ~1 小时 | 100-1000 |

## 14. 一句话总结

**Rosetta 在结构预测领域已有 25 年积累，覆盖 ab initio、同源建模、loop 建模、抗体建模等全套场景，虽然在结构预测本身已被 AlphaFold 超越，但在结构精修、loop 优化、物理评估上仍是 ML 工具必要的补充——本项目用其 `relax` 命令做结构弛豫就是这一补充的体现。**
