# 06 · 核酸、糖类与膜蛋白专题

Rosetta 不止于蛋白——它涵盖了核酸、糖类、膜蛋白等所有生物大分子。本章介绍这些专项工具。

## 1. 核酸（Nucleic Acids）

### 1.1 核酸建模的意义

- **DNA**：基因调控、CRISPR、TALEN、转录因子
- **RNA**：核糖开关、ribozyme、mRNA、lncRNA、tRNA
- **RNA 药物**：mRNA 疫苗（Moderna / BioNTech）、ASO、siRNA、aptamer

### 1.2 Rosetta 核酸工具全景

```

├── 结构预测
│   ├── rna_denovo          # RNA 从头折叠
│   ├── FARFAR2            # RNA Fragment Assembly Refinement
│   ├── stepwise           # 多链 RNA 组装
│   └── rna_helix          # 螺旋建模
├── 设计
│   ├── rna_design         # RNA 序列设计
│   └── rna_motif          # RNA 模体设计
├── 修正

```

### 1.3 rna_denovo

**RNA 从头折叠**：

```bash
rna_denovo.linuxgccrelease \
    -fasta input.fasta \
    -secstruct_file input.secstruct \
    -frag3 frags.3mers \
    -nstruct 100
```

**输入**：
- `input.fasta`：RNA 序列
- `input.secstruct`：二级结构（点括号表示，如 `(((...)))`）
- `frags.3mers`：3 残基片段库

**算法**：

```
1. 用 3-mer 片段拼接形成初始结构
2. 蒙特卡洛采样
3. FARFAR 力场评分
4. 退火到最低能量
```

### 1.4 FARFAR2

**FARFAR**（Fragment Assembly of RNA with Full-Atom Refinement）：

- 比 rna_denovo 更准
- 全原子评分
- 默认协议包含片段 + Monte Carlo + relaxation

### 1.5 ERRASER

**ERRASER**（Enumerative Real-space Refinement ASsembly of RNA）：

- **给定实验结构**（NMR / Cryo-EM）**修正几何**
- 解决原子级几何违规（如 bond length、angle）
- 2012 年发布（Chou et al.）

```bash
erraser.linuxgccrelease \
    -s input.pdb \
    -nstruct 10
```

### 1.6 ERRASER2 / Phenix 集成

**ERRASER2** 集成在 PHENIX 软件中，结合实验密度图（cryo-EM）。

### 1.7 rna_design

**RNA 序列设计**：

- 给定目标三维结构，反向设计序列
- 应用：ribozyme 改造、aptamer 设计

```bash
rna_design.linuxgccrelease \
    -s input.pdb \
    -nstruct 100
```

### 1.8 stepwise

**多链 RNA 组装**：

- 适合大型 RNA（如核糖体、剪接体）
- 把每个结构域单独折叠，然后组装

### 1.9 suitename

**RNA 几何分析**：

- 计算每个核苷酸的"suite"（suiteness）分数
- 评估 RNA 结构的几何合理性

## 2. 糖类（Carbohydrates）

### 2.1 糖类建模的意义

- **糖基化**：~50% 真核蛋白被糖基化
- **糖疫苗**：肿瘤相关糖抗原
- **糖结合蛋白**：凝集素、抗体
- **糖药物**：肝素、糖肽

### 2.2 Rosetta 糖工具全景

```
Rosetta 糖工具
├── 力场
│   ├── glycam_06          # 经典 GLYCAM 力场
│   └── sugar_bb           # Rosetta 集成
├── 残基类型
│   ├── 20+ 常见单糖      # Glc、Gal、Man、Fuc 等
│   └── 各种连接方式       # α/β 1-2, 1-3, 1-4, 1-6
├── 操作
│   ├── glycan_relax      # 糖链弛豫
│   ├── glycan_tree_relax # 糖树弛豫
│   ├── glycosyltransferase  # 糖基转移酶建模
│   └── SimpleGlycosylateMover  # 自动糖基化
└── 应用
    ├── 抗体糖型优化      # ADCC/CDC 增强
    ├── 疫苗设计          # 糖疫苗
    └── 糖-蛋白对接
```

### 2.3 糖残基类型

Rosetta 数据库中包含的常见单糖：

- **Hexoses（六碳糖）**：Glc、Gal、Man、All、Alt、Gul、Ido、Tal
- **Pentoses（五碳糖）**：Ara、Rib、Xyl、Lyx
- **HexNAc**：GalNAc、GlcNAc、ManNAc
- **NeuAc / NeuGc**：唾液酸
- **Fuc**：岩藻糖

### 2.4 glycan_relax

**糖链弛豫**：

```bash
glycan_relax.linuxgccrelease \
    -s glycoprotein.pdb \
    -extra_res_fa glycan.params \
    -nstruct 10
```

**用途**：去除糖链结构的几何冲突。

### 2.5 glycan_tree_relax

**糖树整体弛豫**：

- 处理分支糖链
- 多个分支同时弛豫

### 2.6 SimpleGlycosylateMover

**自动糖基化**：

- 给定蛋白 + N-糖基化位点（N-X-S/T 模体）
- 自动添加标准 N-糖链
- 适合抗体等糖蛋白建模

### 2.7 RosettaCarbohydrate 集成

通过 **RosettaCarbohydrate** 论文系列（2017+），糖建模已成为 Rosetta 的稳定功能。

## 3. 膜蛋白（Membrane Proteins）

### 3.1 膜蛋白的意义

- **~30% 蛋白组**是膜蛋白
- **GPCR**：~50% 现代药物靶点
- **离子通道**：神经科学核心
- **转运蛋白**：药物吸收

### 3.2 膜蛋白建模挑战

- 跨膜区疏水
- 脂双层环境
- 跨膜区拓扑预测
- 内外域几何差异大

### 3.3 RosettaMembrane

**核心协议**：

```bash
mpframework.linuxgccrelease \
    -s membrane_protein.pdb \
    -mp:setup:spanfiles membrane.span \
    -mp:lipids:composition DLPC \
    -nstruct 100
```

**关键概念**：

- **Span file**：定义跨膜区拓扑
  ```
  1 50  # 残基 1-50 跨膜
  70 95 # 残基 70-95 跨膜
  ```
- **MPer 力场**：膜内嵌能量项
- **Implicit Lipid**：隐式脂双层

### 3.4 膜蛋白力场（MPer）

```cpp
class MPMembranePotential;
class MPEnvSmoothEnergy;
class MPNonHelixPenalty;
class MPUnfilledRegionEnergy;
```

**MPer 关键项**：
- **Membrane depth**：残基在膜内的深度
- **Helix orientation**：螺旋倾斜角
- **Lipid exposure**：脂质接触

### 3.5 MPNN / mp_design

**膜蛋白设计**：

```bash
mp_design.linuxgccrelease \
    -s membrane_protein.pdb \
    -nstruct 100
```

### 3.6 RosettaMP / mp_dock

**膜蛋白-蛋白对接**：

```bash
mp_dock.linuxgccrelease \
    -s receptor.pdb ligand.pdb \
    -mp:setup:spanfiles receptor.span ligand.span
```

### 3.7 Glyco-Membrane

**糖基化膜蛋白**：膜蛋白 + 糖链。

### 3.8 膜蛋白成功案例

- **GPCR 建模**：β2-adrenergic receptor 等
- **Ion channel**：K+ channel、CIC chloride channel
- **Transporter**：GLUT1、LeuT
- **ATP synthase**：旋转分子马达

## 6. 跨领域应用案例

### 6.1 案例 1：mRNA 疫苗稳定性优化

```
1. rna_denovo 预测 mRNA 二级结构
2. ERRASER 修正几何
3. rna_design 优化密码子（保留二级结构）
4. 实验验证翻译效率
```

### 6.2 案例 2：抗体糖型优化

```
1. SimpleGlycosylateMover 加标准糖链
2. glycan_tree_relax 弛豫
3. interface_ddg 评估对 Fc 受体亲和力
4. 实验验证 ADCC 活性
```

### 6.3 案例 3：GPCR 配体发现

```
1. mpframework 准备受体结构
2. ligand_dock 跑对接
3. InterfaceAnalyzer 评估
4. hit-to-lead 优化
```

## 8. 一句话总结

**Rosetta 在蛋白之外覆盖了 DNA、RNA、糖类、膜蛋白等所有生物大分子，每个领域都有专门的力场、协议和工具——这是其作为综合性分子建模平台的真正实力。本项目用其 `relax` 工具做结构清洗，未来可扩展到 RNA 优化、糖基化设计、膜蛋白处理等更广领域。**
